# Hackathons
🌿 *A garden of digital prototypes and creative code.*

---

## The Essence
This repository serves as a sanctuary for rapid ideas and competitive coding. It houses a collection of projects born from hackathons and design challenges. From AI-powered kitchen assistants to CSS art and reactive portfolios, each folder represents a sprint towards a new skill or solution.

The code here spans the spectrum of **Python/Flask** logic, **React** interactivity, and pure **CSS** aesthetics.

## Getting Started
Each project acts as an independent entity. To explore a specific creation, navigate to its directory.

**For Python Projects:**
```bash
cd FromFridgeTo
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**For Node/React Projects:**
```bash
cd google_portfolioChallenge
npm install
npm run dev
```
