Ulrike's Portfolio - System Documentation

Overview

This is the React-based portfolio for Ulrike Herold, designed with a "Modern Hacker" aesthetic.

Development

The system is built using:

  • Vite
  • React
  • Framer Motion

Commands

  • npm install: Install dependencies (System Initialization).
  • npm run dev: Start local server (System Boot).
  • npm run build: Compile for production (System Compilation).

Structure

The codebase follows a modular component architecture in src/components.
